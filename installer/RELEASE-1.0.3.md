# Aster VPN 1.0.3

- Автоматическое восстановление продолжается без ограничения числа попыток; пауза увеличивается до пяти минут.
- При смене физического интерфейса, IPv4-адреса или шлюза транспорт перепривязывается при следующем цикле контроля, если включено автоматическое восстановление.
- При отсутствии Ethernet/Wi-Fi клиент ожидает появления сети.
- После перезапуска туннеля сразу проверяется HTTPS. Неудачная проверка сама по себе не останавливает работающие ядра.

Проверено: 160 существующих проверок .NET и дополнительная проверка ограниченных пауз восстановления; сборка Windows. Длительная работа на пользовательской сети отдельно не проверена.
