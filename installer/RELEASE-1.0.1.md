# Aster VPN 1.0.1

- В правилах приложений два режима переименованы в «Через VPN» и «Напрямую, в обход VPN». Поведение приложений сохранено.
- Для сайтов добавлен выпадающий список «Все сайты» / «Через VPN» / «Напрямую, в обход VPN». Отображается список выбранного режима, неактивный список сохраняется. «Все сайты» отключает ограничения раздела; «Через VPN» пропускает через VPN только список, остальные назначения направляет напрямую; режим обхода направляет список напрямую. Домен охватывает поддомены.
- Раздел стран назван «Правила GeoIP». Режимы: «Все страны» / «Через VPN» / «Напрямую, в обход VPN». В первом режиме GeoIP-файлы не загружаются. Во втором VPN доступен для стран списка, остальные направления идут напрямую; в третьем список стран направляется напрямую. В режиме «Через VPN» пустой список направляет остальной трафик напрямую.
- Сохраняется приоритет: служебные подключения → локальная сеть → сайты → приложения → GeoIP → VPN. Более раннее правило может определить маршрут до GeoIP. «Все» в отдельном разделе не отменяет правила других разделов.
- Прежние настройки загружаются: старые GeoIP-исключения остаются прямыми. Старые смешанные правила сайтов действуют до сохранения нового режима; оба списка сохраняются и доступны при переключении режима.
- Применение после сохранения и переподключения. Ядра и защищённый DNS сохранены.

Проверено: 152 проверки .NET, включая все режимы сайтов/GeoIP, пустые списки, сохранение режимов и неактивного списка, старые настройки. Все новые конфигурации приняты настоящим sing-box. Дополнительно 18 маршрутов проверены настоящим ядром через два локальных прокси: все три режима сайтов, корневые домены, поддомены и несовпадающие имена. Интерфейс проверен отдельным рендером XAML без запуска VPN и чтения пользовательских настроек.
