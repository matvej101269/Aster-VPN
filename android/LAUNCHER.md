# Управление из ТВ-лаунчера (Android 1.0.22+)


## Button Mapper: одна кнопка пульта

1. В Aster откройте **Настройки → Кнопка пульта (Button Mapper)**.
2. Прочитайте предупреждение и нажмите **Создать ссылку**. Это разрешает владельцу
   личной ссылки подключать и отключать VPN без повторных подтверждений.
3. Скопируйте показанную ссылку. Она создаётся на устройстве и нигде не публикуется.
4. В Button Mapper выберите действие отправки Intent и заполните:

| Поле | Значение |
|---|---|
| Действие | оставить пустым |
| Пакет | `com.aster.vpn` |
| Компонент | `com.aster.vpn.ControlActivity` (если нужен краткий формат: `com.aster.vpn/.ControlActivity`) |
| Данные | скопированная личная ссылка `astervpn://toggle?key=…` |
| ключ:значение | оставить пустыми |
| Начать как занятие | **включить** |

Одна кнопка переключает VPN; для отдельных кнопок замените в ссылке `toggle` на
`connect` или `disconnect`, сохранив часть `?key=…`. При первом подключении Android
может дополнительно запросить системное разрешение VPN. Сначала настройте сервер.

Личная ссылка — секрет доступа, а не удостоверение пакета Button Mapper. Любое
приложение, получившее её, сможет управлять VPN. Не публикуйте и не пересылайте её.
Создание новой ссылки отзывает старую. Выключение **Управление из лаунчера** отзывает
и ссылку, и все разрешения пакетов. Повторное включение старую ссылку не восстанавливает.
Неверная/отозванная ссылка отклоняется, причина отображается и пишется в журнал без ключа.

Можно не создавать ссылку: укажите действие `com.aster.vpn.action.TOGGLE`, пакет,
компонент и включите **Начать как занятие**, оставив данные пустыми. Если Android
не сообщил caller, Aster попросит подтвердить каждую команду. Постоянное разрешение
неизвестному приложению не сохраняется. Результат обычного startActivity недоступен
Button Mapper; ошибки показываются в Aster и журнале. Внешний Broadcast закрыт.
Совместимость проверяется сборкой и тестами; физический телевизор не использовался.

## Лаунчер с подтверждённым Android caller

Лаунчер может запускать экспортированную Activity из собственной Activity через
`startActivityForResult`. Android удостоверяет пакет вызывающего приложения.
Extras с именем пакета и referrer не используются для выдачи доступа.
При обычном `startActivity` или NEW_TASK Android может не сообщить caller. Тогда Aster запрашивает разовое подтверждение команды либо проверяет личную ссылку кнопки (см. выше). Доступ по имени пакета из extras/referrer не выдаётся.

```java
Intent command = new Intent("com.aster.vpn.action.CONNECT")
    .setComponent(new ComponentName("com.aster.vpn", "com.aster.vpn.ControlActivity"));
startActivityForResult(command, 100);
```

При первом запросе пользователь подтверждает доступ конкретному пакету лаунчера.
При необходимости Aster показывает системное разрешение VPN. Заранее подключать
VPN вручную не требуется, но подписка и выбранный сервер должны быть настроены.
Выключение **Настройки → Управление из лаунчера** отзывает все разрешения лаунчеров.

| Команда | Действие Intent | URI |
|---|---|---|
| Подключить | `com.aster.vpn.action.CONNECT` | `astervpn://connect` |
| Отключить | `com.aster.vpn.action.DISCONNECT` | `astervpn://disconnect` |
| Переключить | `com.aster.vpn.action.TOGGLE` | `astervpn://toggle` |
| Состояние | `com.aster.vpn.action.STATUS` | `astervpn://status` |

URI также запускайте через `startActivityForResult` с пакетом `com.aster.vpn`.
Схема `aster://` и псевдонимы `open`/`close` сохранены. Внешний Broadcast закрыт,
так как не позволяет использовать проверку вызывающей Activity.

CONNECT не перезапускает работающий VPN и ждёт уже начатого подключения.
DISCONNECT отключает VPN, в том числе отменяет подключение; повторная команда успешна.
TOGGLE при подключении отменяет его. STATUS возвращает состояние без открытия UI.

В `onActivityResult` проверьте `RESULT_OK` или `RESULT_CANCELED`, затем extras:
`result` (код), `message` (объяснение), `command`, `active`, `connecting`, `state`.
Успех возвращается после достижения нужного состояния, а не сразу после отправки.
Ожидание ограничено 60 секундами. При тайм-ауте или закрытии Activity команда может
продолжаться: проверьте STATUS. Отказы и итоги доступны в журнале Aster.
Полный список кодов — [DEVELOPMENT.md](../DEVELOPMENT.md#android-1020-обновление-и-управление-из-лаунчера).

## Обновление

Устанавливайте 1.0.22 поверх прежней версии без удаления приложения. Пакет
`com.aster.vpn` и исходная подпись сохранены, настройки остаются на месте.

## Локальная сеть

«Локальная сеть в обход VPN» исключает из IPv4 TUN частные сети 10/8, 172.16/12,
192.168/16, link-local 169.254/16, multicast для обнаружения устройств и broadcast.
Работает на Android 8+ с Xray и AWG. После изменения переподключите VPN.
Прежняя политика блокировки IPv6 не меняется.
