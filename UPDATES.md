# Обновления клиентов

Оба клиента проверяют опубликованные стабильные GitHub Releases репозитория
`matvej101269/Aster-VPN` при запуске и предлагают установить более новую версию.
При каждом запуске оба клиента проверяют наличие новой версии и показывают окно
с кнопками «Обновить» и «Позже». Android также проверяет при повторном открытии
приложения из фона; возврат из QR-сканера или системного окна новую проверку не запускает.
Если клиент Windows скрыт в трее, при обнаружении обновления его окно открывается.
Windows повторяет проверку каждые 6 часов работы.
Проверка вручную: Windows — «Настройки → Проверить обновления» или меню значка в трее,
Android — «Настройки → Проверить обновления».

Публикуйте файлы с точными именами:

- Windows: `AsterVPN-Setup-1.0.7-x64.exe` (версия из `src/AsterVPN.csproj`).
- Android: `AsterVPN-1.0.19-android.apk` (versionName из `android/app/build.gradle`).

Версии платформ независимы; можно прикладывать один или оба установщика.
Клиенты выбирают максимальную версию своей платформы из последних 100 релизов,
пропускают draft/prerelease и файлы без SHA-256 digest GitHub.
Исходники в Git сами по себе не являются обновлением: нужны вложения Releases.
Закрытый репозиторий не подходит для анонимных проверок клиентов.

Файл скачивается после согласия пользователя, проверяются размер и SHA-256.
Окно скачивания показывает процент, скачанный и полный объём в МиБ и этап
проверки файла. Кнопка «Отмена» прерывает загрузку и удаляет неполный файл.
Android дополнительно проверяет имя пакета, versionCode и сертификат установленного
приложения. Для обновлений сохраняйте исходный ключ `android/signing/` вне Git.
Android запрашивает системное разрешение установки из этого источника и открывает
системный установщик. После выдачи разрешения повторите проверку обновления.
Windows штатно отключает VPN и завершает клиент до запуска Inno Setup; после
установки клиент запускается пользователем. Настройки хранятся отдельно.

Сборка: `scripts/build-installer.ps1` и
`android/build.ps1 -Task @('testDebugUnitTest','assembleRelease','lintRelease')`.
Локальные SDK, сетевые ядра, Android AAR/JNI и ключи не входят в Git;
используйте существующие скрипты настройки и инструкции README.

API: https://docs.github.com/en/rest/releases/releases
